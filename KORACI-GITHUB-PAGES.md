# Kako objaviti portfolio na markodakic.github.io

1. Otvori https://github.com/markodakic/cv/settings i na vrhu, **Repository name**, promijeni `cv` u `markodakic.github.io` → **Rename**. Ne treba brisati repo.
2. Otvori novi repozitorij https://github.com/markodakic/markodakic.github.io . Ako je prazan, klikni **uploading an existing file**; ako ima README, klikni **Add file → Upload files**.
3. Raspakiraj ZIP na računalu. Učitaj **sadržaj** mape, uključujući `index.html`, `style.css`, `script.js`, `work.html`, `articles.html`, `cases/`, `assets/`, `content/`, `build.py`, `.nojekyll`, `.pages.yml` i `.github/`. Važno: `index.html` ne smije ostati u dodatnoj podmapi. Ne učitavaj ZIP kao jednu datoteku.
4. Klikni **Commit changes** na dnu stranice.
5. Otvori **Settings → Pages** → **Build and deployment → Deploy from a branch → main → /(root) → Save**.
6. Otvori https://markodakic.github.io/ i provjeri `work.html`, `articles.html` te jedan projekt iz `cases/`.
7. Za kasnije uređivanje članaka koristi `content/articles.json` i priloženi `build.py` ili Pages CMS, ali ne objavljuj nedovršene članke u javni repozitorij.

Fotografija se nalazi u `assets/profile.jpg`. Statistika na početnoj stranici: 20+ godina IT-a, 10+ godina eCommercea i 13 detaljnih opisa projekta.
